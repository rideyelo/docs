This page tracks merged pull requests in `rideyelo/yelo-frontend`, newest week first. Weeks start on Monday.

Each change ships one of two ways:

- **OTA**: JavaScript-only. It reaches installed binaries through EAS Update once staged and promoted.
- **Native**: It changes a native input (`package.json`, the lockfile, `app.json`, `app.config.ts`, `patches/`, or native config). It needs a new store build.

Unmarked product changes are OTA. For how this is decided, see [Mobile releases](/engineering/mobile/releases#ota-versus-native-rebuild).

<Update label="Week of September 21, 2026" description="Coordinate-only ride stops, guarded ride controls, vehicle artwork fixes, seat minimums from vehicle types, and top-location cleanup">
  **Rides**

  - Ride stops now need only coordinates. Pins without an address or name reach ride options, and the API resolves the address. [#641](https://github.com/rideyelo/yelo-frontend/pull/641). See [Rider experience](/engineering/mobile/rider-experience#draft-creation).
  - "Current location" stays in the rider's own UI and is no longer sent as a stop label. Unresolved GPS stops go as coordinates. If the API can't resolve an address, the stop picker opens. [#638](https://github.com/rideyelo/yelo-frontend/pull/638)
  - Driver ride controls are disabled while the server reports a pending transition for the current ride, and the button reads **Updating ride…** until the ride state catches up. Payment-failure pushes refresh ride state. [#640](https://github.com/rideyelo/yelo-frontend/pull/640). See [Current ride](/engineering/mobile/driver-experience#current-ride).
  - The pickup vehicle card resizes vehicle artwork. Pricing artwork from the selected quote only shows when the assigned vehicle type matches it, so a rematch to a different type shows the assigned vehicle instead. [#646](https://github.com/rideyelo/yelo-frontend/pull/646). See [Rider experience](/engineering/mobile/rider-experience).
  - End-to-end coverage for idle auto-assignment, stranded queue recovery, arrival, and restart. [#634](https://github.com/rideyelo/yelo-frontend/pull/634). See [Testing](/engineering/testing).

  **Drivers**

  - The vehicle seat picker reads its minimum from the vehicle type's `min_seats` instead of a hard-coded 3, so drivers can't pick a count the API rejects. [#636](https://github.com/rideyelo/yelo-frontend/pull/636). See [Vehicle types and catalog](/engineering/domains/vehicle-types-and-catalog).

  **Profile**

  - The profile tab, drive bubble, profile edit sheet, and driver hub load photo thumbnails before the full photo. The auto-queue explainer no longer picks an empty thumbnail over the real photo. [#645](https://github.com/rideyelo/yelo-frontend/pull/645). See [Profile photos](/engineering/domains/user-profile-and-status#profile-photos).

  **Search and map**

  - Top locations are deduplicated by canonical Yelo place, unverified entries are hidden, and empty browse sections are omitted. Community-content pushes refresh only that community's search context. [#635](https://github.com/rideyelo/yelo-frontend/pull/635). See [Community top locations](/guides/community-top-locations).
  - Removed the "coming" tag from the map search bar. [#631](https://github.com/rideyelo/yelo-frontend/pull/631)

  **Tooling**

  - Every event now records the loaded OTA update id and runtime. [#641](https://github.com/rideyelo/yelo-frontend/pull/641)
  - The backport workflow triggers only on PRs merged into `main`. [#642](https://github.com/rideyelo/yelo-frontend/pull/642). See [Backports](/engineering/mobile/releases#backports).
</Update>

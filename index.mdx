Yelo is a college-focused rideshare and community transportation platform. Riders request rides in the mobile app. Drivers, often students, accept and complete them. Both belong to a **community**, usually one school. Operators run the marketplace from the web dashboard. Drivers can be independent or belong to a **fleet**, a third-party operator that has its own Stripe account and pays its drivers.

These docs are internal. They cover product concepts, dashboard operations, and the engineering internals of the three codebases.

## How a ride works

1. A rider picks a pickup and dropoff. The API quotes a price for each available vehicle type.
2. The rider confirms. The ride goes on the community's ride board.
3. An online driver in the same community accepts the ride, or gets it through auto-queue. The API authorizes payment on the driver's or fleet's Stripe Connect account.
4. The driver picks up the rider, confirms pickup with the rider's code, and drops them off.
5. A tip window opens. When it closes, the API captures the fare and tip, and Stripe settles the payout.

See [Ride lifecycle](/concepts/ride-lifecycle) and [Payments and payouts](/concepts/payments-and-payouts) for the details.

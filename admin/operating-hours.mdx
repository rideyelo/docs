---
title: "Fleet operating hours"
description: "Import fleet operating hours from Google Calendar and view them by zone in the Yelo dashboard."
---

Yelo imports each fleet's operating hours from a Google Calendar. Partners edit their schedule in Google Calendar. The Yelo dashboard shows a read-only copy of the latest successful import, broken down by service zone.

Use operating hours when you want admins, fleet managers, and operators to see when a fleet serves each zone of a community.

<Note>
  Imported hours are informational. They do not affect ride visibility. Riders see rides based on your existing ride settings, not the calendar.
</Note>

## How it works

- Each Google Calendar binds to one fleet and one service community.
- Event titles start with a bracketed prefix, such as `[FREE]`. The prefix maps the event to a zone.
- Yelo checks Google about every five minutes and replaces the imported hours when an import succeeds.
- If an import fails, Yelo keeps showing the last successful import.
- All times display in the community's timezone.

## Prerequisites

Before you attach a calendar, you need:

- Admin access to the Yelo dashboard.
- An active service community assigned to the fleet. Add one in the **Service communities** tab of the fleet if needed.
- A valid service area for the community, so Yelo can resolve its timezone.

## Connect the calendar owner

Yelo reads calendars through a single Google account, the calendar owner. Connect it once for your organization.

<Steps>
  <Step title="Open Access">
    In the dashboard, go to **Access**. Find the **Google Calendar for operating hours** card.
  </Step>
  <Step title="Connect Google">
    Click **Connect Google Calendar** and sign in as the owner account shown on the card. Grant access when Google prompts you.
  </Step>
  <Step title="Confirm the connection">
    After Google redirects you back, the card shows **Connected as** followed by the owner email.
  </Step>
</Steps>

If the card shows **Google connection setup is pending**, the importer is not configured yet and you cannot connect. If the owner's access expires, the fleet calendar shows **The calendar owner needs to reconnect Google**. Click **Reconnect Google** on the **Access** page to restore imports.

## Attach a fleet calendar

Yelo does not create calendars for you. Create one manually for each fleet and community pair.

<Steps>
  <Step title="Create a calendar in Google">
    In the connected owner's Google account, create a new, separate calendar for the fleet and community. Set its timezone to the community's timezone. The attach form displays the timezone to use.
  </Step>
  <Step title="Copy the calendar ID">
    In Google Calendar, open the calendar's **Settings** and go to **Integrate calendar**. Copy the **Calendar ID**. It looks like `…@group.calendar.google.com`.
  </Step>
  <Step title="Share editing access">
    In Google Calendar, share the calendar with the partners who maintain the schedule. Give them permission to make changes to events.
  </Step>
  <Step title="Open the fleet's hours">
    In the dashboard, go to **Fleets**, open the fleet, and select the **Hours** tab. Choose the service community.
  </Step>
  <Step title="Attach the calendar">
    Click **Attach calendar**. Paste the ID into **Google Calendar ID**.
  </Step>
  <Step title="Set zone prefixes">
    Enter a prefix for each zone you want to schedule. Leave unused zones blank. Enter prefixes without brackets.
  </Step>
  <Step title="Save">
    Click **Attach calendar**. Yelo verifies the calendar and shows **Calendar saved. Hours will appear after the next import.**
  </Step>
</Steps>

To point the fleet at a different calendar, click **Change calendar ID** and then **Save calendar ID**. Yelo keeps the existing prefixes. It clears the old imported hours until the new calendar syncs.

## Zone prefixes

A prefix selects one zone, even when zones share a name. For example, two zones named FREE can use the prefixes `FREE-1` and `FREE-2`.

Prefixes must follow these rules:

- 1 to 32 characters.
- Letters, numbers, hyphens, or underscores only.
- Must start with a letter.
- Unique within the calendar.

Yelo converts prefixes to uppercase.

### Write event titles

Start each Google event title with the exact prefix in square brackets. The rest of the title is up to you.

```text
[FREE-1] Afternoon service
```

To schedule the same hours in several zones, list the prefixes in one set of brackets, separated by commas:

```text
[FREE-1,FREE-2] Afternoon service
```

Follow these rules for events:

- Use timed events with a start and end time. All-day events are not imported.
- For overnight service, such as 10pm to 2am, set the end date to the following day.
- When you change a recurring schedule, edit the entire series.

In the **Hours** tab, expand **Event title prefixes and setup** to see each zone's prefix and an example title. Click **Copy title for [PREFIX]** to copy the example.

### Rename a prefix

Admins can rename a prefix after the calendar is attached. Fleet and operator viewers see prefixes as read-only.

<Steps>
  <Step title="Edit the prefix">
    In **Event title prefixes and setup**, click **Edit [PREFIX]** next to the zone.
  </Step>
  <Step title="Save the new prefix">
    Enter the new prefix without brackets and click **Save prefix**.
  </Step>
  <Step title="Update Google event titles">
    Update every Google event that uses the old prefix, including entire recurring series.
  </Step>
</Steps>

<Warning>
  Yelo does not rewrite Google event titles. Events that still use the old prefix fail to import until you update them. Yelo keeps showing the previously imported hours until an import succeeds.
</Warning>

A rename keeps the zone and calendar binding. It also schedules a fresh import. If another admin changed the prefix first, or the new prefix is already in use, the dashboard shows an error. Reload the calendar and try again.

## View imported hours

The **Imported operating hours** section in the **Hours** tab shows:

- The community timezone and the **Last imported** time.
- **Edit in Google Calendar**, which opens the calendar in Google. You need editing access shared by the owner.
- A status message when the latest import is pending or failed.

Click **Show preview** to open the schedule.

### Seven-day view

The **Next 7 days** view shows imported hours for today and the following six days in the community's timezone. It marks the current time. Events that cross midnight appear on both days, labeled **Next day** and **From previous day**.

### Zone map

The zone map shows each zone's boundaries in its calendar color. Select a zone on the map or in the zone list to filter the schedule. Select **All zones** to clear the filter.

### Import problems

When some events cannot be imported, the dashboard lists each problem event with a fix. Common fixes:

| Problem | Fix |
| --- | --- |
| Title has no registered prefix | Start the title with a registered prefix, such as `[FREE-1]`. |
| All-day event | Use a timed event with a start time. |
| Missing or invalid end time | Set an end time after the start time. |
| Calendar timezone mismatch | Set the Google calendar timezone to the community's timezone. |

Fix the events in Google Calendar. The next import retries automatically.

## Community timezone

Yelo sets each community's timezone automatically from its service area, including daylight saving time. You cannot set the timezone manually. When you edit a community's service area, the community editor previews the resulting timezone.

The attached Google Calendar's timezone must match the community's timezone.

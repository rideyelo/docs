This page is an index. It lists names, the repository that reads each one, whether it is required, and a one-line purpose. It never lists secret values.

- For how `yelo-api` loads configuration, validation rules, and defaults, see [API configuration](/engineering/api/configuration).
- For a working local setup, see [Local development](/engineering/local-development).
- For `VITE_*` usage per site, see [Web conventions](/engineering/web/conventions#environment-variables).
- For EAS profiles and release workflows, see [Mobile releases](/engineering/mobile/releases).

"Required" means the process fails fast without it. Required values are:

- **Yes**: `Validate()` in `yelo-api` `internal/utilities/config/config.go:399-454`, or a site's `metadata.requiredBuildEnv` in `yelo-web`.
- **E2E**: `validateE2E` requires it in E2E mode.
- **Cond.**: required only when a related flag is on.

This page lists the numbers that shape Yelo's runtime behavior, with the code location of each. Values come from `main`. Change the code, not this page, when you need a different value.

**Path conventions.** API paths are relative to `yelo-api/internal/`, with these abbreviations:

- `constants.go` is `utilities/config/constants.go`.
- `config.go` is `utilities/config/config.go`.
- `main.go` is `yelo-api/cmd/api/main.go`.
- `queue.go` is `notify/queue/queue.go`.
- `queries/` is `data/repository/queries/`.

Mobile paths are relative to `yelo-frontend/`, and web paths to `yelo-web/`.

For environment variables that override some of these values, see [Environment variables](/reference/environment-variables). For flags that switch behavior on or off, see [Feature flags](/reference/feature-flags).

<Warning>
`RideAcceptTimeout` (25s), `NoDriversAvailableDelay` (45s), `CommunityWaitBuffer` (5 min), and `RecentlyOnlineDriverNotificationWindow` (30 min) in `constants.go:7-16` are never referenced. The effective values are the hard-coded 30-second offer window and the 60-minute recently-online window listed below.
</Warning>

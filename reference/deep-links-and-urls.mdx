This page maps every URL the system serves, generates, or handles. It covers public hosts, Dub short domains, app schemes and universal links, and the deep link paths the mobile app understands. Paths are relative to each repository root: `yelo-api`, `yelo-web`, and `yelo-frontend`.

<Note>
Which Firebase site answers on which custom domain is configured in the Firebase and Cloudflare consoles, not in code. Where this page says a site is "likely" served on a domain, the evidence is the API CORS list and cross-links in code.
</Note>

## Deep links the app handles

Expo Router maps each file under `app/` to a path. Route groups in parentheses do not appear in the URL. `app/+native-intent.tsx` rewrites incoming system URLs before routing.

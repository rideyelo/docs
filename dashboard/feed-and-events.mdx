title: "Events and The Spot"
description: "Create and publish community events, feature an event or place as The Spot, and preview the community feed riders see in the Yelo app."
---

The **Events** page manages the content riders see in their community: events they can RSVP to, and **The Spot**, the one event or place featured at the top of the community feed. You can preview the resulting feed on the **Community** page.

For how events and the feed work in the rider app, see [Events and the community feed](/concepts/events-and-feed).

## Prerequisites

- An `admin` or `intern` dashboard role to manage events. Interns only work in their assigned community, and can only submit drafts for review. See [Dashboard roles and access](/administration/dashboard-roles).
- An `admin` role to manage **The Spot**.
- A community selected in the top bar.

## Open the Events page

Open **Events** in the **Community** group of the sidebar. The page has two tabs:

- **Events**: every event in the community.
- **The Spot**: the featured item. Only admins see this tab.

The old `/spot` and `/feeds` URLs redirect to this page. The old `/feed` URL redirects to the **Community** page.

## Find an event

The **Events** tab splits events by status: **All**, **Draft**, **Pending Review**, **Published**, and **Archived**. The **Pending Review** tab shows a **!** badge when events are waiting for review.

Use **Search events...** to filter the current tab. The table shows each event's photo, **Name**, **Date**, **Attendees**, **Status**, and **Created** date.

## Create an event

<Steps>
  <Step title="Open the form">
    Select **Create Event**.
  </Step>
  <Step title="Enter the details">
    Fill in the fields in [Event fields](#event-fields). Only **Name** is required.
  </Step>
  <Step title="Save">
    Select **Create Event**.
  </Step>
</Steps>

New events start as **Draft**. Riders don't see an event until it's published. See [Review and publish events](#review-and-publish-events).

To edit an event, open the actions menu on its row and select **Edit**. Then select **Save Changes**.

### Event fields

| Field | Description |
| --- | --- |
| **Name** | The event name. Required. |
| **Share link slug** | The path for the event's share link, `event.yelo.link/{slug}`. See [Share an event](#share-an-event). |
| **Description** | What the event is about. |
| **Photo** | An image for the event card. |
| **Start Time** and **End Time** | When the event happens. |
| **Release Time** | When the event becomes visible. |
| **Close Time** | When the event stops accepting RSVPs. |
| **Location** | A place from the community's locations. Search to find it. See [Manage locations](/dashboard/community-map#manage-locations). |
| **Ticket URL** | A link where riders can buy tickets. |
| **Price** | The ticket price. |
| **Tickets Available** | How many tickets are available. |
| **Tags** | A comma-separated list, such as `social, formal`. |

### Share an event

Yelo fills in **Share link slug** from the event name as you type. After you edit the slug yourself, it stops following the name.

A slug can have 1 to 64 letters, numbers, and hyphens, and must start and end with a letter or number. The form turns spaces into hyphens and removes other characters.

Select **Copy share link** to copy `https://event.yelo.link/{slug}`.

## Review and publish events

Open the actions menu on an event's row to move it to its next status.

| Current status | Actions |
| --- | --- |
| **Draft** | **Submit for Review** |
| **Pending Review** | **Approve & Publish**, **Return to Draft** |
| **Published** | **Archive** |
| **Archived** | **Restore to Draft** |

Interns only see **Submit for Review**. An admin must approve and publish the event. Yelo rejects any status change that isn't listed above.

## Set The Spot

The Spot is the single featured item at the top of a community's feed. It points to either a published event or a location. Each community has at most one active Spot.

<Steps>
  <Step title="Open the form">
    On **The Spot** tab, select **Set The Spot**.
  </Step>
  <Step title="Choose what to feature">
    Pick a **Spot Type** of **Event** or **Location**. Then search for and pick the **Event** or **Location**. Only published events appear in the list.
  </Step>
  <Step title="Optionally override the content">
    Fill in any **Override Fields**. See the table below.
  </Step>
  <Step title="Schedule it">
    Under **Scheduling**, set **Starts At** and **Ends At**, and leave **Active** on to turn the Spot on right away.
  </Step>
  <Step title="Save">
    Select **Set The Spot**.
  </Step>
</Steps>

Activating a new Spot deactivates the community's current Spot.

| Field | Description |
| --- | --- |
| **Title Override** | A custom title. Leave it blank to use the event or location name. |
| **Description Override** | A custom description. |
| **CTA Label** | The button text, such as `Learn More`. |
| **CTA URL** | Where the button goes. |
| **Display Start Time** and **Display End Time** | The window when the Spot appears in the feed. |
| **Image** | A custom image. |
| **Starts At** | When the Spot becomes active. |
| **Ends At** | When the Spot expires. |
| **Active** | Turns the Spot on or off immediately. |

The **Active Spot** card shows the current Spot, its type, its call to action, and its display and scheduled windows. Select **Edit** to change it, or **Deactivate** to turn it off. When no Spot is active, the card shows **No active spot**.

The **History** table lists past Spots with their **Type**, **Referenced Item**, **Title Override**, **Created**, and **Updated** dates.

## Preview the community feed

The **Community** page shows a **Community feed** preview below the community metrics. It shows the community content riders see in the app, in order:

1. The Spot, if it's active and inside its display window.
2. The community's events.
3. Recent ride activity.
4. Popular places, marked **Popular place**.

The Spot, events, and popular places appear only on the first page. Use **Previous** and **Next** to page through ride activity.

<Note>
  Friends and private activity vary by rider, so the app can show a rider more than this preview does.
</Note>

To choose which popular places appear, see [Community top locations](/guides/community-top-locations).

The **Presence** tab on the **Supply & Demand** page shows live app activity. Use it to see how many riders and drivers have the app open, where they are, and which screen they're on.

## Prerequisites

- An admin account. See [Dashboard roles and access](/administration/dashboard-roles).

## Open presence

1. Click **Supply & Demand** in the sidebar.
2. Click the **Presence** tab.
3. Pick a community from the community filter, or leave it on **All Communities**.

The **Live · 10s** badge means the tab refreshes every 10 seconds.

<Note>
  Presence data is live, not historical. A user counts as online only if their app reported in within the last two minutes.
</Note>

## Presence metrics

| Card | What it shows |
| --- | --- |
| **Online Users** | Users whose app reported presence in the last two minutes. |
| **Online Drivers** | Online users who are driving. |
| **Warm Pool** | Drivers who aren't online but were active in the matching warm pool within the last hour. |
| **Unmatched Rides** | Confirmed rides still waiting for a driver. |

For how the warm pool is used in matching, see [Matching and auto-queue](/concepts/matching-and-auto-queue).

## Distributions

Three charts break down online users:

| Chart | Breakdown |
| --- | --- |
| **By Screen** | The app screen each user is on. |
| **App State** | Whether the app is in the foreground or background, as reported by the device. |
| **Network Type** | The device's network connection type. |

## Map view

The **Map View** tab plots each online user and warm driver. The legend shows the count of each type.

| Color | Marker |
| --- | --- |
| Blue | Online driver |
| Green | Online rider |
| Amber | Warm pool driver |

## Live users

The **Live Users** tab lists online users and warm pool drivers, 50 per page. Use **Previous** and **Next** to page through the list.

| Column | Description |
| --- | --- |
| **User** | Name, with a dot for the type: blue for drivers, green for riders, orange for warm drivers. |
| **Community** | The user's community. |
| **Screen** | The screen the app is showing. |
| **App State** | The app's reported state. |
| **Battery** | Battery level, as a percentage. |
| **Last Seen** | Time since the last presence report. |

Click a row to open the user's details. See [User directory](/dashboard/user-directory).

The **Links** page lists Yelo's [Dub](https://dub.co) short links with their clicks and sign-ups. Use it to create a short link for a campaign, fix a link's destination, archive a link you no longer use, or check the card a messaging app shows when someone shares a link.

## Prerequisites

- An admin account. See [Dashboard roles and access](/administration/dashboard-roles).

## Open links

Expand **Administration** in the sidebar and click **Links**. The page URL is `/links`.

The page opens on the **Campaigns** folder.

## Folder tabs

Each tab is a Dub folder, with its link count. The counts leave out archived links. Tab names come from Dub and show with a capital first letter.

| Tab | What it holds |
| --- | --- |
| **Campaigns** | Hand-made marketing links. New links go here by default. |
| **Fleet** | Fleet driver join links and fleet payout onboarding links. The API creates these. |
| **Unsorted** | Links that aren't in any folder. |
| **All folders** | Nothing until you search. Then it searches every folder, including referral links. |

Other Dub folders also appear as tabs. The folder that holds per-user referral links isn't a tab because it has one link per user. To find a referral link, open **All folders** and search for it.

Turn on **Show archived** to include archived links. Archived links show an **archived** badge.

## Totals

The cards above the table summarize the links you're looking at.

| Card | What it shows |
| --- | --- |
| **Links** | Links in the current view. |
| **Clicks** | Clicks on those links. |
| **Sign-ups** | Sign-ups Dub attributes to those links. |
| **Click to sign-up** | Sign-ups divided by clicks. Shows **—** when there are no clicks. |

When a view has more than one page, the cards read **Clicks (this page)** and **Sign-ups (this page)**. They only add up the links on the current page. **Links** still shows the total for the whole view.

## Link table

| Column | What it shows |
| --- | --- |
| **Short link** | The link's key. Links on domains other than `yelo.link` include the domain, such as `pay.yelo.link/<key>`. Click it to copy the full short link. |
| **Destination** | Where the link sends people. |
| **Tags** | The link's Dub tags. |
| **Clicks** | Total clicks. |
| **Sign-ups** | Sign-ups attributed to the link. |
| **Last click** | Date of the most recent click, or **—** if nobody has clicked it. |

A link with an **untracked** badge doesn't have conversion tracking on. Dub doesn't pass a click ID to its destination, so the link can't attribute sign-ups.

## Search and sort

How search and sort work depends on the size of the view.

| View | Search matches | Sort | Paging |
| --- | --- | --- | --- |
| A folder with 100 links or fewer | Key, destination, and tags | Any column, in either direction | One page |
| A folder with more than 100 links, or **All folders** | Key and destination | **Clicks** or **Last click** only, highest or newest first | 100 links per page |

In a small folder, every word you type must appear in the key, destination, or a tag, in any order. A word can also match the key with letters skipped. For example, `ndfl` finds `NDflyer`.

In a large folder or **All folders**, Dub runs the search and sort. Column headers you can't sort by show as plain labels. Use the arrows below the table to move between pages.

## Keep the list current

The dashboard saves each listing in your browser and shows it right away on your next visit. If the saved copy is older than 30 minutes, the dashboard fetches a new one in the background.

- Click **Refresh** to load the current view and the folder tabs straight from Dub. It also clears the saved copies of every other view.
- Click a row to reload that link from Dub. The row updates with its latest values.

The dashboard also refreshes after you create or edit a link.

## Create a link

<Steps>
  <Step title="Open the form">
    Click **New link**.
  </Step>
  <Step title="Choose the short link">
    Enter the key after `yelo.link/`. Use 1 to 64 letters, digits, hyphens, or underscores, starting with a letter or digit.
  </Step>
  <Step title="Set the destination">
    The destination defaults to `https://joinyelo.com/get`, which sends phones to their app store. It must start with `https://`.

    Use a `joinyelo.com` page so the click is carried into sign-up.
  </Step>
  <Step title="Pick a folder">
    Choose **Campaigns** (the default) or **Fleet**.
  </Step>
  <Step title="Save">
    Click **Save**. The dashboard shows **Link created**.
  </Step>
</Steps>

Every link you create has conversion tracking on, so its sign-ups are counted.

If the key is already taken, the dashboard shows "That short link is already in use". Pick another key.

## Edit a link

1. Click **Edit** on the link's row. The form opens with the link as Dub holds it now, not the saved copy in your browser.
2. Change the **Short link**, **Destination**, or **Folder**.
3. Turn on **Archived** to archive the link, or turn it off to restore it.
4. Click **Save**. The dashboard shows **Link updated**.

The **Folder** field only appears for links in **Campaigns** or **Fleet**. You can move a link between those two folders. You can't move it back to **Unsorted**.

### Read-only links

Some links show **API-managed** instead of **Edit**. You can preview them but not change them.

| Link | Why it's read-only |
| --- | --- |
| Links the API creates, such as fleet join links and fleet payout onboarding links | The API rewrites them, so a manual edit would be overwritten. |
| Domain roots, such as `yelo.link` with no key | They control what the bare domain does. |
| Referral links on `join.yelo.link` | The API creates one per user. |

## Check a link preview

The preview check shows the card a messaging app builds when someone shares the link.

1. Click **Preview** on the link's row. This works for every link, including referral links.
2. Wait while the dialog shows **Fetching the link as a crawler…**.

The dialog shows the card's image, title, description, and domain.

| Field | What it means |
| --- | --- |
| **Card from** | **Dub (the link's own card)** when Dub serves the link's own title, description, and image. Otherwise, the landing page's domain, followed by **(the landing page's tags)**. |
| **Lands on** | The page the crawler ended on after redirects. |
| **Missing title**, **Missing description**, **Missing image** | Tags the card doesn't have. Messaging apps show a plainer card without them. |

If the preview fails, the dialog shows the reason the API returned. For example:

- "url must be an https short link on a Yelo short domain" means the link isn't on `yelo.link`, `pay.yelo.link`, `event.yelo.link`, or `join.yelo.link`.
- "Could not load the link: …" means the API couldn't fetch the link. The rest of the message says why.

If the API gives no reason, the dialog shows "Could not load this link's preview."

## Errors

| Message | What to do |
| --- | --- |
| Could not load links. Try refreshing. | Click **Refresh**. |
| Could not refresh links | Try again. |
| Could not load the latest version of this link | The dashboard couldn't read the link from Dub before opening the form. Try again. |
| key must be 1-64 letters, digits, hyphens or underscores | Change the key. |
| url must be an https address | Use a destination that starts with `https://`. |

The **Access** page is where admins manage who can use the Yelo dashboard. Use it to invite interns, fleet managers, and admins, change which community or fleets they can see, and manage your own account settings.

The old **Settings** page URL, `/settings`, redirects to **Access**. Your profile settings now live on its **Account** tab.

For what each role can see and do, see [Dashboard roles and access](/administration/dashboard-roles).

## Prerequisites

- An `admin` dashboard role.

## Open the Access page

Open **Access** in the **Administration** group at the bottom of the sidebar. The group starts collapsed, so select **Administration** to expand it.

The page has five tabs:

| Tab | What it's for |
| --- | --- |
| **Interns** | Interns and the community each one is locked to. |
| **Fleet Managers** | Fleet managers and their fleet assignments. |
| **Admins** | Admins. |
| **Account** | Your own profile settings. |
| **Google Calendar** | The Google Calendar connection for fleet operating hours. |

The **Interns**, **Fleet Managers**, and **Admins** tabs show a count of users. Use **Search by name or email...** to filter them.

## Review dashboard users

Each user list shows **Name**, **Email**, and **Last Active**. The **Interns** list adds a **Community** column, which shows **Unassigned** when an intern has no community. The **Fleet Managers** list adds an **Assignments** column, which shows **None** when a manager has no fleets.

Select a row to open the user's details, including when they **Joined** and their **Last Sign In**.

## Invite a user

<Steps>
  <Step title="Open the form">
    Select **Invite User**.
  </Step>
  <Step title="Choose a role">
    Pick **Intern**, **Fleet Manager**, or **Admin** under **Role**.
  </Step>
  <Step title="Enter the email">
    Enter the person's **Email Address**.
  </Step>
  <Step title="Set the scope">
    For an intern, pick a **Community**. The intern is locked to this community.

    For a fleet manager, add one or more **Fleet Assignments**. Pick a community, pick a fleet in that community, and select **+ Add**. Repeat for each fleet.

    Admins don't need a scope.
  </Step>
  <Step title="Send">
    Select **Send Invitation**, check the summary, and select **Send Invite**.
  </Step>
</Steps>

Yelo emails an invitation with the role and scope already set. When the person accepts and signs in, they have access right away.

<Warning>
  If the email already belongs to a dashboard account, Yelo updates that account instead of sending an invitation:

  - Inviting an existing user as an **Intern** or **Admin** replaces their current role and scope.
  - Inviting an existing user as a **Fleet Manager** makes them a fleet manager and adds the new fleet assignments to any they already have.

  Check the **Interns**, **Fleet Managers**, and **Admins** tabs before you invite someone who might already have an account.
</Warning>

## Change a user's scope

### Interns

1. On the **Interns** tab, select the intern.
2. In **Intern Details**, pick a new **Community**.
3. Select **Save Changes**.

### Fleet managers

1. On the **Fleet Managers** tab, select the manager.
2. In **Fleet Manager Details**, remove an assignment with its remove icon, or add one: pick a community and a fleet, and select **+ Add**.
3. Select **Save Changes**.

Each assignment pairs one fleet with one community. The dashboard won't add an assignment that already exists.

### Admins

**Admin Details** is read-only.

When a user's role or scope changes, their dashboard clears its cached data and reloads with the new scope.

## Manage your account

The **Account** tab shows **Profile Settings** for your own dashboard account. Use it to manage your profile and sign-in security. Changes here apply only to your account, not to your role.

## Connect Google Calendar

The **Google Calendar** tab connects the Google account that owns fleet operating-hours calendars. See [Connect the calendar owner](/admin/operating-hours#connect-the-calendar-owner).

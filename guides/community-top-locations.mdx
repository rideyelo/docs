title: "Community top locations"
description: "Choose up to four featured places that riders see when they open search in your community."
---

Top locations are up to four featured places that appear in a **Top locations** section when riders open search in the Yelo app. Each community has its own four slots. Use them to highlight venues your riders go to often, such as bars, stadiums, or event spaces.

Each slot points to a verified Yelo place. It does not store a copy of the name, address, or coordinates. Yelo looks up the place details from its map providers and keeps one shared record per place. Search and the community map both use that record, so a place always shows the same details in both.

## Prerequisites

- Access to the Yelo dashboard for your community. See [Dashboard roles and access](/administration/dashboard-roles).

## Open the top locations settings

1. In the dashboard, select your community.
2. Go to the **Searches** page at `/searches`. The page has no sidebar entry, so enter the path directly.
3. Find the **Top locations** card.

The card shows the visibility and refresh settings, the four numbered slots, and the time of the last refresh.

## Show top locations in the app

Top locations are shown by default in every community except the default community, where they are hidden. This applies to existing communities and to new communities that have no saved setting yet.

To show the section to riders, turn on **Show top locations in the app**.

When you turn this setting off:

- Riders no longer see the **Top locations** section.
- Yelo keeps your saved slots.
- Automatic refresh pauses.
- **Refresh unpinned slots now** is unavailable.

## Choose a place for a slot

1. Next to a slot, click **Choose place**. If the slot already has a place, click **Replace**.
2. In **Search for a venue**, enter the venue name.
3. Select the correct result. Yelo verifies the place and shows its name, address, and coordinates.
4. Click **Pin place**.

A place you choose yourself is **Pinned**. Each place can only fill one slot per community.

## Pinned and automatic slots

Each filled slot shows one of these labels:

| Label | Meaning |
| --- | --- |
| **Pinned** | You chose or pinned this place. Refreshes never replace it. |
| **Automatic** | A refresh filled this slot. The next refresh can replace it. |
| **Needs verification** | Yelo could not verify this place. It is hidden in the app until you choose it again. |

Use these actions on each slot:

- **Pin**: Keep an automatic place in its slot so refreshes skip it.
- **Replace**: Choose a different place for the slot.
- **Clear**: Empty the slot. The next refresh can fill it again.

<Note>
  Places carried over from the older top-locations list start as **Needs verification**. Yelo checks them in the background and verifies the ones it can match. To fix any place that stays unverified, use **Replace** to choose it again.
</Note>

## Automatic refresh

A refresh fills unpinned slots with popular places in your community. Yelo ranks places by rider activity. Each search selection from the last 30 days counts as one point. Each like counts as ten, and likes count no matter how old they are. See [Search and places](/engineering/location/search-and-places). Only public places inside your service area are eligible, and each place appears once at most.

Automatic refresh is off by default. To turn it on, turn on **Update unpinned slots every 24 hours**. You can only change this setting while **Show top locations in the app** is on.

When automatic refresh is on, Yelo refreshes the unpinned slots about every 24 hours. Pinned slots stay where they are.

A refresh that finds fewer new places than you have automatic slots clears all automatic slots first, then fills only as many as it found. For example, four automatic places can become one. Pin places you want to keep.

A refresh keeps your current list in these cases:

- The map providers are unavailable.
- No eligible places are found to replace the current ones.
- You change the slots or settings while the refresh runs. Your change wins.

## Refresh once

To fill unpinned slots right away, click **Refresh unpinned slots now**. This works in manual mode too, so you can fill slots once without turning on automatic refresh.

Yelo queues the refresh and updates the card when it finishes. Pinned slots stay in place.

## How top locations appear in rider search

When a rider opens search, the **Top locations** section shows your verified places in slot order. The section appears above the rider's personal recent places.

- Places marked **Needs verification** are hidden.
- Each place appears once.
- If the community has no visible top locations, the app omits the section and still shows the rider's recent places.
- After you save changes, the app refreshes its top locations automatically. Riders do not need to update the app.

## Settings reference

The dashboard stores these settings for each community:

```json
{
  "enabled": false,
  "automatic": false,
  "refreshed_at": null
}
```

| Field | Default | Description |
| --- | --- | --- |
| `enabled` | `true`, or `false` for the default community | Shows the **Top locations** section in the app. |
| `automatic` | `false` | Refreshes unpinned slots about every 24 hours. |
| `refreshed_at` | `null` | Time of the last successful refresh. |
